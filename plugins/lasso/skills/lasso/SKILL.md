# Clevon Lasso

사용자는 브라우저에서 화면 요소를 찍거나 영역을 끌어 코멘트를 남기고 [N건 보내기]를 누른다.
그 피드백이 이 세션으로 바로 들어오고, 세션은 고친 뒤 짧게 보고한다.

CLI 는 이 스킬 폴더의 `bin/lasso.mjs` 다. 아래 `LASSO` 는 그 절대 경로, `ROOT` 는 작업 중인
프로젝트의 절대 경로(git 최상위)다. 둘 다 매번 절대 경로로 넘긴다. 셸의 현재 폴더에 기대지 않는다.

## 켜기

1. **개발 서버 포트를 정한다.** 사용자가 말한 포트를 쓴다. 말하지 않았으면 떠 있는 서버
   (`lsof -iTCP -sTCP:LISTEN -P | grep node`)와 `package.json` 의 dev 스크립트에서 찾는다.
   서버가 꺼져 있으면 먼저 띄운다.
2. **중계 서버를 백그라운드로 띄운다.** Bash `run_in_background`:
   `node LASSO <포트> --project ROOT`
   중계 주소는 `<포트>+100` 이다(겹치면 `--listen <포트>`). 출력 첫 줄에 주소와 수신함 위치가 나온다.
   이미 그 포트로 떠 있으면 다시 띄우지 않는다.
3. **감시를 건다.** Monitor 도구, `timeout_ms: 1800000`:
   `node LASSO watch --project ROOT`
   파이프(`| grep` 등)를 붙이지 않는다. 출력이 버퍼에 갇혀 피드백이 늦게 온다.
   `watch` 는 시작할 때 아직 넘기지 않은 피드백부터 내보내므로, 쉬는 동안 쌓인 것도 이때 들어온다.
4. **사용자에게 중계 주소(`http://localhost:<포트>+100`)를 알려 준다.** 원래 주소와 같은 화면에
   피드백 도구가 얹혀 있다. 코드를 고치면 원래처럼 바로 반영된다.
   도구 사용법도 한 줄로: 요소를 누르거나 끌어서 코멘트, Space 로 둘러보기 전환, 모아서 [N건 보내기].

## 피드백이 들어오면

Monitor 알림 한 건이 `── Lasso 피드백 <id>` 로 시작하는 묶음 하나다. 본문은 사용자가 쓴 내용이다.

1. 코멘트마다 `Components:` 줄(React 컴포넌트 이름, 안쪽이 먼저)과 `Selector:`·텍스트로 코드 위치를 찾는다.
2. `이미지:` 의 파일을 Read 로 열어 사용자가 가리킨 부분을 본다.
3. 고친다. 요청 범위만 고친다. 해석이 크게 갈리면 묻는다.
4. 화면에서 확인한다. 브라우저 확인이 가능하면 직접 보고, 사용자가 쓰던 탭은 닫지 않는다.
   도구 UI 는 Shadow DOM(`clevon-lasso` 요소) 안에 있어 일반 선택자로는 안 잡힌다.
5. 무엇을 바꿨는지 코멘트별로 짧게 보고한다. 커밋은 하지 않는다.

## 감시가 끝나면

Monitor 는 30분이면 끝난다. 사용자가 멈추라고 하지 않았다면 먼저 `node LASSO idle --project ROOT` 로
마지막 활동(중계 주소로 화면 열기·새로 고침, 피드백 보내기) 뒤 몇 분 지났는지 본다.

- **60 미만** → 같은 명령으로 Monitor 를 바로 다시 건다.
- **60 이상** → 사용자가 자리를 비운 것으로 보고 Monitor 를 다시 걸지 않는다. 대신 Bash
  `run_in_background` 로 `node LASSO wait --project ROOT` 를 띄우고 한 줄로만 알린다
  ("1시간 동안 피드백이 없어 감시를 쉰다. 화면을 열거나 피드백을 보내면 다시 켠다").
  `wait` 는 사용자가 중계 주소의 화면을 열거나 피드백을 보내면 끝난다. 끝났다는 알림이 오면
  Monitor 를 다시 건다. 쉬는 동안 온 피드백은 `watch` 가 시작할 때 들어온다.
- 쉬는 중에 사용자가 이 세션에 말을 걸어도 돌아온 것이다. `wait` 를 TaskStop 하고 Monitor 를 다시 건다.

`watch` 는 넘긴 위치를 기억하므로 끊긴 사이에 온 피드백도 다시 걸 때 들어온다.

## 쉬기·끄기

- "잠깐 쉬어" → Monitor(또는 `wait`)만 TaskStop. 중계 서버는 그대로 두어 사용자는 계속 피드백을 보낼 수 있고,
  다시 켤 때 3번부터 하면 쌓인 것부터 받는다.
- "꺼줘" → Monitor(또는 `wait`)와 중계 서버 모두 TaskStop.

## 알아 둘 것

- 수신함은 프로젝트 밖 `~/.clevon-lasso/<폴더이름>-<해시>/` 에 있다(`node LASSO path --project ROOT`).
  프로젝트에는 파일을 만들지 않는다.
- 쿠키를 특정 포트에 묶었거나 절대 주소로 리다이렉트하는 앱은 중계 주소에서 어긋날 수 있다. 그럴 땐
  개발 환경에서만 페이지에 `<script src="http://localhost:<중계포트>/__lasso/client.js" async></script>`
  를 넣는 방법이 있다. 프로젝트 파일을 바꾸는 일이므로 사용자에게 먼저 묻는다.
